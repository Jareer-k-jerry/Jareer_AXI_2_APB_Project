## 3. Detailed Lint Warning Categorization & Dispositions

### Warning 1: Unused Input Port — `PSLVERR`
- **Location:** `rtl/axi2apb.sv`, Line 93: `input logic PSLVERR`
- **Description:** Port `PSLVERR` is declared in the port list but is never read or referenced in the FSM or datapath.
- **RTL Consequence:** When an APB slave returns `PSLVERR = 1'b1`, the bridge does not convert it into an AXI `SLVERR` response.
- **Scoreboard / TB Disposition (WAIVED):** Documented as an intended architectural property of this bridge. The scoreboard explicitly verifies that `BRESP` and `RRESP` remain `OKAY` (2'b00) even when `PSLVERR` is driven high.

### Warning 2: Unused Sideband and Burst Inputs
- **Location:** `rtl/axi2apb.sv`, AW/AR channel ports: `AWBURST`, `AWLOCK`, `AWCACHE`, `AWPROT`, `AWQOS`, `AWREGION`, `WSTRB`, `WLAST`
- **Description:** These signals pass through input FIFO slices into internal registers but are not evaluated by the FSM.
- **RTL Consequence:** The FSM operates strictly on single-beat 32-bit transfers. Burst lengths and write strobes are ignored.
- **Scoreboard / TB Disposition (WAIVED):** Testbench constraints configure single-beat transfers (`len == 0`, `size == 3'b010`, `strb == 4'hF`). Unsupported burst modes are documented in the verification plan.

### Warning 3: Hardcoded OKAY Response Status
- **Location:** `rtl/axi2apb.sv`, Lines 344 & 352:
  ```systemverilog
  BRESP = `OKAY;
  RRESP = `OKAY;
  ```
- **Description:** Constant values are assigned to `BRESP` and `RRESP`.
- **RTL Consequence:** Neither `EXOKAY`, `SLVERR`, nor `DECERR` can ever be generated by the bridge.
- **Scoreboard / TB Disposition (WAIVED):** Scoreboard expects 2'b00 (`OKAY`) for all valid completions.

### Warning 4: Implicit 32-bit Address Truncation / Bit-Slicing
- **Location:** `rtl/axi2apb.sv`, Line 173:
  ```systemverilog
  assign PADDR = address[APB_ADDR_WIDTH-1:0];
  ```
- **Description:** Bit-slice extraction from internal `address` register.
- **RTL Consequence:** Valid address mapping when `AXI4_ADDRESS_WIDTH == APB_ADDR_WIDTH` (default 32 bits).
- **Scoreboard / TB Disposition (WAIVED):** Word-aligned address generation (`addr[1:0] == 2'b00`) ensures proper byte addressing.

### Warning 5: FSM Latch Free Verification
- **Location:** `rtl/axi2apb.sv`, `always_comb` block (Lines 331–435).
- **Description:** All control signals (`read_req`, `write_req`, `ARREADY`, `AWREADY`, `WREADY`, `BVALID`, `RVALID`, `RLAST`, `NS`) have default initializations at the top of the block before the `case (CS)` statement.
- **RTL Consequence:** **Zero inferred latches**. Synthesis and elaboration tools report clean combinational logic.
- **Status:** **CLEAN / PASSED**.

### Warning 6: Asynchronous Reset with Synchronous Release
- **Location:** `rtl/axi2apb.sv`, sequential process (`always_ff @(posedge ACLK or negedge ARESETn)`).
- **Description:** Asynchronous active-low reset assertion cleanly clears state register `CS` to `IDLE` and resets `RDATA_Q` to 0.
- **Status:** **CLEAN / PASSED**. Verified across smoke tests.
